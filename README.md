# Xenia Collections website

React + Vite + GSAP (ScrollTrigger) + Lenis smooth scroll + Framer Motion.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production files in /dist (upload to Netlify / Vercel / any host)

- Phone / social links / map: `src/lib.js`
- Products & prices: `src/data/products.json` (set "price": 500 or null for "Get a quote")
- Images & videos: `public/img`, `public/vid`
